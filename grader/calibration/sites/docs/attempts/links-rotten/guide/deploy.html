Deploy

A Lumen site is plain files, so it can be hosted anywhere that serves static pages.

Build the site

lumen build
Built 42 pages in 0.8 s -> dist/

Upload

Copy the dist folder to your host. With the built-in command you can upload straight to an S3-compatible bucket:

lumen deploy --target s3://my-bucket

Roll back

Every deploy keeps the previous build. Run lumen deploy --rollback to put it back.
