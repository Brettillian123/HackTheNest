Configuration

Every Lumen site has one settings file, lumen.config.json, in its root folder.

A starting file

{
  "title": "My site",
  "theme": "paper",
  "output": "dist",
  "baseUrl": "/"
}

Options you will change most

title appears in the browser tab and the header. theme picks one of the built-in looks: paper, slate or mono. The full list is in the reference.

Profiles

Use a profile to change settings for one environment only, such as a staging server.

lumen build --profile staging
