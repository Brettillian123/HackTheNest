Install Lumen

Lumen runs anywhere Node.js runs. Installing it takes one command.

Requirements

  • Node.js 20 or newer
  • npm 10 or newer
  • About 40 MB of free disk space

Install with npm

npm install -g lumen-cli

Check the install

Run the version command. It should print the version number and exit.

lumen --version
lumen 2.4.0
