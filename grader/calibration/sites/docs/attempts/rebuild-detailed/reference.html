Reference

Every setting, command and environment variable Lumen understands.

On this page
  • Configuration file
  • Command line
  • Environment variables

Configuration file

OptionTypeDefaultDescription
titlestring"Untitled"Site name shown in the header and tab.
themestring"paper"One of paper, slate or mono.
outputstring"dist"Folder the built site is written to.
baseUrlstring"/"Path the site is served from.
draftsbooleanfalseInclude pages marked as drafts.
languagestring"en"Language code set on every page.

Command line

lumen new <name>    Create a new site
lumen serve         Preview with live reload
lumen build         Write the site to the output folder
lumen deploy        Upload the output folder

Environment variables

VariableEffect
LUMEN_PROFILEProfile to use when none is given on the command line.
LUMEN_CACHE_DIRWhere build caches are kept. Defaults to .lumen-cache.
LUMEN_NO_COLORSet to 1 to turn off coloured output.
