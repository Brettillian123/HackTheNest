# Challenge reference library

These are generic target pages for prompt-reproduction exercises. Each numbered case has its own HTML and uniquely named CSS file. The HTML links only to the CSS beside it; target pages render in isolated iframes, separate from PromptDyno's app styles.

| Folder | HTML | Dedicated CSS | Target |
|---|---|---|---|
| `01-simple-shape/` | `index.html` | `circle.css` | Red circle on white |
| `02-shape-study/` | `index.html` | `shape-study.css` | Three primary-color shapes in an aligned row |
| `03-profile-card/` | `index.html` | `profile-card.css` | Purple and yellow profile card |
| `04-coffee-shop/` | `index.html` | `coffee-shop.css` | Orange and cobalt coffee landing page |
| `05-login-form/` | `index.html` | `login-form.css` | Split-screen login form |

Use the target arrows or the challenge list to cycle through every reference. The selected target is saved in the browser. Titles, difficulty labels, and scoring keywords are configured in `frontend/scripts/app.js`.
